# WR503 GPST Monitor

WR503 雙臂晶圓機器人的取片狀態觀測與振動分析工具。對機器人只發送唯讀的 RASeMIO `GPST` 查詢，無法移動機器人或寫入 I/O。

## 下載與使用

1. 到 [Releases](../../releases) 下載 `WR503-GPST-Monitor.exe` 與 `wr503_app_config.json`，放在同一個資料夾。
2. 雙擊 `WR503-GPST-Monitor.exe`。首次啟動會在旁邊建立 `wr503_status.sqlite3`。
3. Windows 出現 SmartScreen 警告時，點「其他資訊」再點「仍要執行」。本程式未做程式碼簽章，屬內部使用。

系統需求：Windows 10 或以上，64 位元。不需安裝 Python。

## 設定檔欄位

`wr503_app_config.json` 與 EXE 放在一起，內容如下。

| 欄位 | 說明 | 預設 |
|---|---|---|
| `host` | 機器人 IP | 192.168.10.11 |
| `port` | RASeMIO 埠 | 4000 |
| `threshold` | 振動門檻，單位 g | 0.3 |
| `cutoff` | 低通截止頻率，單位 Hz | 200 |
| `target_hz` | 重採樣目標頻率，單位 Hz | 512 |
| `debounce_samples` | 超標判定的去彈跳樣本數 | 3 |

## 觀測歷史

1. 只需設定目標主機 IP 與 RASeMIO 埠。程式會讀取 Windows 作用中的網路介面與子網路遮罩，自動綁定涵蓋目標位址且最精確的介面。
2. 按 **連線** 開始觀測。每一次成功的 GPST 回應都會自動保存，沒有另外的擷取按鈕。
3. 大方塊在未連線時為灰色並顯示 `--`，連線時為綠色並顯示模式 `0/1/2/3`。
4. 暫時性失敗會讓方塊轉灰、在歷史中留下真實空隙，並自動重試。
5. 歷史預覽為唯讀，最新在前，可依時間與模式篩選並分頁。

TCP 逾時 3 秒、重試間隔 10 秒、連續五次失敗停止、GPST 輪詢 0.1 秒（10 Hz）是內部預設值，不開放操作者調整。

觀測資料表只保留 UTC 時間戳與數值模式，另有內部列編號供保存使用。

## 振動分析

1. 匯入感測器 CSV。
2. 確認解析出的本地起始時間。CSV 沒有日期時間資訊時，手動輸入。
3. 設定低通截止與目標取樣率（預設 200 Hz 與 512 Hz）。截止頻率必須低於來源與目標的奈奎斯特頻率。
4. 與狀態歷史重疊時，可選取僅上臂模式 1、僅下臂模式 2、雙臂模式 3。多選為聯集；不選則分析整份 CSV。
5. 未知狀態區間的背景為灰色。有涵蓋的區間依 GPST 上色：`0` 無片為淺藍，`≥1` 有片為深藍。曲線與指標使用各自獨立處理的連續區間。
6. 感測器起始時間只精確到秒，且感測器與 RASeMIO 的時鐘各自獨立，GPST 遮罩可能與振動資料有偏移。在圖上左右拖曳可滑動遮罩，放開後以該偏移重新分析。偏移量（秒，正值代表 GPST 較晚）也可在 **GPST 對時偏移 (s)** 直接輸入，按 **偏移歸零** 重置，匯入新的 CSV 時也會歸零。縮放狀態會在重新分析後保留，以便放大對齊。分析範圍固定為整段錄製。

整段感測器資料都沒有狀態歷史時，模式控制項停用，全段分析仍然可用。

結果包含 X/Y/Z 的 RMS、P99、P99.9、最大絕對加速度、門檻分子與分母、百分比、事件次數、分析時長、每分鐘事件數與最長事件時間。

## 開發

```powershell
uv sync
uv run python run.py
uv run pyinstaller --noconfirm WR503-GPST-Monitor.spec
```

打包產物是 `dist\WR503-GPST-Monitor.exe`。開發模式的資料庫放在專案根目錄，打包後則放在 EXE 旁邊。

規格與議題紀錄在 `.scratch/wr503-app-v2/`，領域詞彙表在 `CONTEXT.md`。

### 乾淨環境測試

`sandbox-test.wsb` 用 Windows Sandbox 在沒有 Python 的環境驗證打包結果。首次使用需以系統管理員執行下列指令並重新開機。

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All
```
